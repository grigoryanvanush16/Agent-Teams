## Предпочтения

- **Автономность**: делай сам максимум, спрашивай только по крупным решениям
- **Текст**: пиши по-человечески, без AI-вводных вроде «Давайте рассмотрим», «Важно отметить»
- **Ошибки**: перед финализацией сверяй с эталоном. Не повторяй одну и ту же ошибку дважды
- **Ответы**: без саммари в конце — я сам вижу результат

- Скриншоты и медиа — в `0.AI_Hub/knowledge/projects/<проект>/`. Если непонятно куда — `knowledge/screenshots/unsorted/`

## Agent Teams

Тулкит агентов под Claude Code. Можно вызывать напрямую или через Router.

### Запуск

```bash
claude
```

(Опционально для параллельной работы нескольких агентов: `tmux new -s claude` → внутри `claude`.)

### Настройки проекта

В `.claude/settings.json`:
```json
{
  "env": { "CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS": "1" },
  "teammateMode": "tmux"
}
```

### Агенты под недвижимость

| # | Агент | Назначение | Когда звать |
|---|-------|-----------|-------------|
| 1 | `router` | Маршрутизация запросов | Когда задача неоднозначная — пусть сам решит, кому передать |
| 2 | `deep-research` | Глубокий ресёрч | Анализ района, сравнение ЖК, исследование рынка аренды |
| 3 | `parser` | Парсинг сайтов в таблицу | Собрать срез цен с ЦИАН/Авито по фильтру |
| 4 | `news-digest` | Дайджест новостей | Новости по застройщикам, ипотечным программам, законодательству |
| 5 | `doc-analyzer` | Разбор документов | Проверка ДКП, выписки ЕГРН, технических паспортов |
| 6 | `report-generator` | Отчёты из данных | Отчёт собственнику по показам, аналитика по сделкам месяца |
| 7 | `meeting-notes` | Транскрипты встреч | Заметки после встречи с клиентом или собственником |
| 8 | `youtube-analyzer` | Разбор YouTube | Выжимка из обзоров ЖК, интервью застройщиков |

### MCP-зависимости

| MCP | Используется в | Fallback |
|-----|---------------|----------|
| Brave Search | deep-research, news-digest | WebSearch + WebFetch |
| Playwright | parser | WebFetch |
| Telegram | meeting-notes, router | — |
| yt-dlp + whisper + ffmpeg | youtube-analyzer | — (обязательны) |
