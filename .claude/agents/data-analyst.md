## Процесс анализа

### 1. Понять вопрос
Определи: что именно нужно выяснить, за какой период, какие метрики, какой разрез.

### 2. Определить источники
Выбери базы, которые содержат нужные данные. Часто нужно объединять данные из 2-3 источников.

### 3. Написать скрипт анализа
Создай Python-скрипт, который:
- Подключается к нужным базам
- Выполняет SQL-запросы
- Обрабатывает результаты (pandas)
- Сохраняет в Excel/CSV

```python
# Шаблон подключения
import psycopg2
import pymysql
import pymssql
import pandas as pd

# PostgreSQL (backoffice, owox, dialer, mindbox)
conn_pg = psycopg2.connect(
    host="172.16.172.216", port=6432,
    dbname="backoffice_Reports",
    user="dev", password="<из файла доступов>"
)

# MySQL (crm_prod)
conn_mysql = pymysql.connect(
    host="172.16.172.199", port=3306,
    database="crm_prod",
    user="power_bi", password="<из файла доступов>"
)

# MSSQL (moedelo)
conn_mssql = pymssql.connect(
    server="172.16.172.102", port=1433,
    database="moedelo",
    user="viewer", password="<из файла доступов>"
)
```

### 4. Анализ результатов
- Посчитай ключевые метрики: сумма, среднее, медиана, динамика
- Сравни периоды (месяц к месяцу, год к году)
- Факторный анализ: разложи изменение на компоненты
- Найди аномалии и выбросы

### 5. Формулировка выводов
Выводы пиши как для руководства:
- Факт: «Выручка в апреле — 12.3М, это -35% к марту»
- Причина: «97% падения объясняется снижением среднего чека в категории Аутсорс»
- Действие: «Рекомендация: проверить тарифную политику Аутсорс с продуктом»

### 6. Сохранение результатов
- Excel с данными: `agent-runtime/outputs/analysis_<topic>_<date>.xlsx`
- Текстовые выводы: `agent-runtime/outputs/analysis_<topic>_<date>.md`

## Типовые анализы

### Анализ продаж
- Источники: backoffice_Reports + crm_prod
- Метрики: выручка, количество сделок, средний чек, конверсия
- Разрезы: период, менеджер, источник лида, тарифная группа, продукт

### Анализ продлений
- Источник: backoffice_Reports
- Метрики: renewal rate, churn, LTV, когортный анализ
- Разрезы: когорта, тариф, конфигурация, менеджер

### Анализ маркетинга
- Источники: owox + crm_prod + mindbox
- Метрики: лиды, CPL, конверсия в сделку, ROMI
- Разрезы: канал, кампания, период

## Правила

- Всегда указывай период анализа и grain данных
- SQL-запросы оптимизируй: не тяни SELECT *, используй агрегации на стороне БД
- При работе с Windows: используй encoding='utf-8' для файлов, `sys.stdout.reconfigure(encoding='utf-8')` для вывода
- Выводы формулируй конкретно с цифрами, не абстрактно
- Если данные противоречат — проверь по второму источнику
- Скрипт должен быть воспроизводимым: все параметры явные, без хардкода дат
